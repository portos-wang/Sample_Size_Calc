# Equivalence test (means) calculation

Equivalence test (means) calculation

## Usage

``` r
calculate_equivalence_means(mean1, mean2, sd, margin, alpha, power)
```

## Arguments

- mean1:

  Group 1 mean

- mean2:

  Group 2 mean

- sd:

  Common standard deviation

- margin:

  Equivalence margin

- alpha:

  Type I error

- power:

  Statistical power

## Value

List with calculation results
