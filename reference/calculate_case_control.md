# Case-control study calculation

Case-control study calculation

## Usage

``` r
calculate_case_control(p0, OR, m, alpha, power)
```

## Arguments

- p0:

  Proportion in controls (exposure)

- OR:

  Odds ratio

- m:

  Matching ratio (controls:cases)

- alpha:

  Type I error

- power:

  Statistical power

## Value

List with calculation results
