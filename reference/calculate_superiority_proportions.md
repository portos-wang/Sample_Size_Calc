# Superiority test (proportions) calculation

Superiority test (proportions) calculation

## Usage

``` r
calculate_superiority_proportions(p1, p2, margin, alpha, power)
```

## Arguments

- p1:

  Group 1 proportion

- p2:

  Group 2 proportion

- margin:

  Superiority margin

- alpha:

  Type I error

- power:

  Statistical power

## Value

List with calculation results
