# Two independent means comparison calculation

Two independent means comparison calculation

## Usage

``` r
calculate_two_means(mean1, mean2, sd, alpha, power)
```

## Arguments

- mean1:

  Group 1 mean

- mean2:

  Group 2 mean

- sd:

  Common standard deviation

- alpha:

  Type I error

- power:

  Statistical power

## Value

List with calculation results
