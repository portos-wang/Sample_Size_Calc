# Diagnostic comparison (two tests) calculation

Diagnostic comparison (two tests) calculation

## Usage

``` r
calculate_diagnostic_comparison_two(
  p1,
  p2,
  prevalence,
  paired,
  psi,
  alpha,
  power
)
```

## Arguments

- p1:

  Test 1 accuracy

- p2:

  Test 2 accuracy

- prevalence:

  Disease prevalence

- paired:

  Paired design?

- psi:

  Discordant pair proportion (for paired design)

- alpha:

  Type I error

- power:

  Statistical power

## Value

List with calculation results
