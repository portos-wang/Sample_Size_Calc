# Non-inferiority test (means) calculation

Non-inferiority test (means) calculation

## Usage

``` r
calculate_non_inferiority_means(mean1, mean2, sd, margin, alpha, power)
```

## Arguments

- mean1:

  Group 1 mean

- mean2:

  Group 2 mean

- sd:

  Common standard deviation

- margin:

  Non-inferiority margin

- alpha:

  Type I error

- power:

  Statistical power

## Value

List with calculation results
