# Diagnostic accuracy (single test) calculation

Diagnostic accuracy (single test) calculation

## Usage

``` r
calculate_diagnostic_accuracy_single(prob, d, prevalence, alpha)
```

## Arguments

- prob:

  Expected accuracy (sensitivity or specificity)

- d:

  Desired precision (half-width of CI)

- prevalence:

  Disease prevalence

- alpha:

  Type I error

## Value

List with calculation results
